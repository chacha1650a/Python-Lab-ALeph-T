## 실험 1 — 동의어 (R3 미달 원인)

"비밀번호 규칙?"은 완벽하지만, 문서가 "오늘의 와 포인트"로 제시한 **"패스워드 규칙?"은 재현되지 않았다.**

| 질문 | 1위 | 거리 |
|---|---|---|
| 비밀번호 규칙? | 보안규정 1조(비밀번호) ✅ | 0.354 |
| 패스워드 규칙? | 보안규정 4조(피싱) ❌ | 0.850 |
| 패스워드 규칙 알려줘 | 보안규정 4조(피싱) ❌ | 0.845 |

원인은 DB나 코드가 아니라 **모델의 어휘**다. 모델에 직접 물어본 단어 유사도(코사인, 1.0=동일):

| 단어쌍 | 유사도 |
|---|---|
| 비밀번호 ↔ password | **0.975** (완벽히 이해) |
| 패스워드 ↔ password | **0.307** (외래어 표기를 모름) |
| 패스워드 ↔ 비밀번호 | 0.370 |

즉 이 다국어 모델은 한글 외래어 표기 "패스워드"를 의미 있는 토큰으로 보지 못한다.
참고로 한국어 특화 모델 `jhgan/ko-sroberta-multitask`로 바꿔 측정하면
패스워드↔비밀번호 0.702, "패스워드 규칙?" 1위가 비밀번호 1조로 정상 동작한다.
(이번 실습은 문서 원문 유지를 택했으므로 모델은 교체하지 않았다.)

## 실험 2 — 없는 질문 → THRESHOLD 실측

**문서 기본값 1.1은 이 환경에서 사용할 수 없다.** 규정 밖 질문의 1위 거리가 최대 0.989로
전부 1.1보다 가까워, 폴백이 한 번도 발동하지 않는다.

| 규정 안 질문 | 1위 거리 | | 규정 밖 질문 | 1위 거리 |
|---|---|---|---|---|
| 비밀번호 규칙? | 0.354 | | 휴가 신청 방법 | 0.720 |
| USB 써도 되나요? | 0.405 | | 점심 메뉴 추천 | 0.814 |
| 소프트웨어 설치해도 되나요? | 0.536 | | 주차장 어디야? | 0.845 |
| 피싱 메일 받으면? | 0.624 | | 야구 경기 결과 | 0.944 |
| 백업 얼마나 자주? | 0.669 | | 오늘 날씨 어때? | 0.989 |

두 분포 사이인 **THRESHOLD = 0.70** 채택 (`answer.py`, `rag_llm.py`에 반영).

한계: "패스워드 규칙?"(0.850), "재택근무할 때 뭐 해야 하나요?"(0.842)는 규정 안 질문인데도
임계값을 넘어 폴백된다. 실험 1의 어휘 문제와 같은 원인이며, 완벽히 분리하는 임계값은 존재하지 않는다.

## 심화 (§9) — 미실행

`rag_llm.py`는 작성·문법 검증까지 완료했으나, 이 PC에 **ollama가 설치돼 있지 않아 실행하지 못했다.**
ollama 설치 + `ollama serve` 실행 후 `MODEL` 값을 받아둔 모델명으로 맞추면 동작한다.
